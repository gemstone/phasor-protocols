      SimulatedTimestampGenerator Class

      Generates simulated frame timestamps for paced (e.g., file replay) input by advancing a frame counter across the sub-second distribution of a defined frame rate, instead of reading the wall clock for every frame.

      Remarks

      Millisecond aligned wall-clock timestamps, i.e., AlignToMillisecondDistribution(Ticks, Int32), cannot represent every frame slot when the frame rate exceeds 1,000 frames per second. For example, at 3,000 frames per second only about 2,000 distinct timestamps per second are produced, some slots twice, so consumers aligning to a 3,000-slot grid lose about a third of the frames. Reading the wall clock per frame also misplaces frames when replay pacing stalls and then bursts.

      This generator anchors to the wall clock on the first frame, then issues each following frame the next slot of the FrameRate distribution at full tick resolution. Every timestamp lands exactly on the grid used by RoundToSubsecondDistribution(Ticks, Int32) and AlignToSubsecondDistribution(Ticks, Int32, Int64), each slot is used once, and consecutive frames are exactly one frame period apart. If the counter drifts from the wall clock by more than MaximumDrift, for example after a long stall in replay, the generator re-anchors to the wall clock so timestamps stay near real time.
